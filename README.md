# MAVK1-designtool-CUBE

## Using fonts

The bundled Space Mono font is awaited during setup because this project's p5 `loadFont()` returns a promise. To use another font, drop a `.ttf` or `.otf` file onto the font box in the GLYPHS menu, or click the box to choose a file. The glyph buttons update to the characters available in that font; selecting a button updates the 3D glyph and exports.
